## 这是什么

本项目最终交付物是 **7 个 Agent Skills 技能包**，每个技能包对应一种常见慢性病。
每个技能包**解压即可推理，无需重新训练**，同时附完整训练脚本，可**逐字节复现**。
所有技能包都构建在**公开可获取的人群调查数据**之上（NHIS / BRFSS / NHANES），不依赖任何私有数据。

> **不是论文复现，不是 demo。** 每个模型都附带：数据下载与 SHA256 校验脚本、训练脚本、推理脚本、完整的验证指标、以及一份写清所有局限的数据溯源文档。

## 为什么做这个

做慢病风险预测时，最常见的三个坑：

**坑一：用诊断指标去预测诊断结果。**
用 HbA1c 预测糖尿病、用血脂值预测高脂血症、用血压值预测高血压——这些指标**本身就是诊断标准**。这样做出来的 AUC 很高，但模型学到的是"用诊断标准预测诊断结果"，是循环论证，没有预测价值。

**坑二：数据集人群不具代表性。**
经典的 Pima Indians Diabetes Database 只有 **768 例**，且其官方原始文件写明：

> *"all patients here are females at least 21 years old of Pima Indian heritage"*

——**仅女性、≥21 岁、仅 Pima 印第安人**，数据中甚至没有性别列。用它训练出的模型无法外推到男性或其他族裔。

**坑三：稀有结局用准确率评估。**
糖尿病阳性率 10.88%，"一律判为无病"就有 **89.12%** 的准确率。此时报告"准确率 89%"毫无意义。

**本项目针对这三点做了系统性设计**——详见 [建设思路](#-建设思路)。

## 数据来源

**全部使用美国政府公开数据（Public Domain），无需注册、无需数据使用协议、可自由下载。**

| 数据集 | 说明 | 覆盖人群 | 官网 |
|--------|------|----------|------|
| **NHIS** | National Health Interview Survey，全国住户抽样入户访谈 | 美国非机构化平民，≥18 岁 | [cdc.gov/nchs/nhis](https://www.cdc.gov/nchs/nhis/) |
| **BRFSS** | Behavioral Risk Factor Surveillance System，全美电话调查 | 美国成人，年样本 40 万+ | [cdc.gov/brfss](https://www.cdc.gov/brfss/) |
| **NHANES** | National Health and Nutrition Examination Survey，含体格检查与实验室检测 | 美国平民，每周期约 5,000 成人 | [cdc.gov/nchs/nhanes](https://www.cdc.gov/nchs/nhanes/) |
| **Pima Indians** | Pima Indians Diabetes Database（仅用于版本演进对照） | ⚠️ 仅 Pima 印第安女性，≥21 岁，768 例 | [openml.org/d/37](https://www.openml.org/d/37) |

### 数据选型调研：我们评估并放弃了什么

选数据时我们系统评估了多个来源，**并把否决理由记录下来**——这部分通常不会出现在论文里，但对复现者最有价值：

| 数据源 | 评估结论 | 否决理由 |
|--------|----------|----------|
| **SEER** 癌症登记库 | ❌ 不可用于风险预测 | 经全变量字典检索确认：**零**吸烟/饮酒/BMI/家族史变量。它是纯病例登记，也**无健康对照**。只适合做发病率与生存率校准 |
| **NHANES** 做癌症/稀有结局 | ❌ 例数不足 | 胃癌在全部 11 个周期（1999–2023）合计仅 **59 例**（每周期 3–10 例）；幽门螺杆菌仅 1999–2000 有 |
| **NHIS 教育/收入变量** | ❌ 无法跨年对齐 | **2016–2018 的成人文件根本没有 `EDUC`/`RATCAT` 变量**，2019 年才引入，无法做 10 年一致建模 |
| **NHIS 体力活动/饮酒** | ❌ 隔年轮换 | 2019 年改版后体力活动**仅偶数年（2020/2022/2024）**采集；饮酒 2019 年后成人文件无此变量 |
| **NHIS 2011–2015** | ❌ 格式不可用 | 仅提供定长 ASCII，各年记录长度不同（827/1086/1021/1087/904），布局 PDF 不含字节位置 |
| **Kaggle 大样本慢病数据集** | ⚠️ 逐个甄别 | 部分为合成数据（详见 [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) 的甄别方法） |

> **一个反直觉的发现**：我们把 BRFSS 的**冠心病/脑卒中/慢阻肺**模型建在 44 万+ 样本上，而把**糖尿病/高脂血症**建在 NHIS 的 29 万样本上——不是因为 NHIS 更好，而是因为 BRFSS **不采集癌种**、NHIS 的高血压/糖尿病问法在 2019 年改版后可跨年对齐。**数据选型由变量的可得性决定，不由样本量决定。**

详细的逐年变量对齐表、SHA256 校验值、官方码本逐字核实记录，见每个 skill 包内的 `data/DATA_PROVENANCE.md`。

## 建设思路

### 统一流程

7 个模型使用**完全相同**的流水线，便于横向比较：

```
官方微数据 (CDC FTP)
   │  ① fetch_data.py  下载 + 逐文件 SHA256 校验 + 跨问卷时代变量对齐
   ▼
标准化队列 CSV (data/*.csv，附 SHA256)
   │  ② 特征阶梯实测：分层加入候选特征，按 8 个随机种子做留出评估
   ▼
确定最简特征集
   │  ③ train_model.py
   ▼
XGBoost 模型 + 阈值 + 风险分档 (models/、results/)
   │  ④ predict.py / batch_predict.py
   ▼
个体风险概率 + 风险等级 + 参考实测率
```

### 设计原则

**原则一：只使用风险因素，不纳入诊断性指标。**

判定标准很明确——**如果该指标本身就是这个病的诊断依据，就不能作为特征**：

| 疾病 | 被排除的指标 | 原因 |
|------|--------------|------|
| 糖尿病 | HbA1c、空腹血糖、OGTT | HbA1c ≥6.5%、FPG ≥126 mg/dL 本身即诊断标准 |
| 高脂血症 | 总胆固醇、LDL-C、甘油三酯 | 同上 |
| 高脂血症 | 降脂药使用史、近 12 月查血脂 | 服药/受检本身即意味着已确诊 |
| 高血压 | 血压值本身 | 同上 |

**原则二：不使用人群划分属性。**

性别、种族等变量在**数据构建阶段即未提取**（见各 `fetch_data.py` 的 `OUTPUT_COLUMNS` 白名单）。这是**结构性保证**，而非训练时的口头约定——模型文件里根本不存在这些字段。

> **这个选择有代价，我们把它量化了。** 以甲状腺癌为例：加入性别后 AUC 从 0.6394 升至 **0.7004**（+0.061）。这是一个明确的权衡，我们把两种结果都公开，由使用者自行决定。

**原则三：不使用体现代理变量。**

心血管病高发人群常有"不吃早餐""睡眠差"这类特征——它们不是病因，而是**社会经济地位与就医行为的代理**。纳入它们会提高 AUC，但模型学到的是"谁更容易被诊断"，而非"谁更容易生病"。教育/收入同理。

**原则四：稀有结局用 AUC / PR-AUC / 平衡准确率评估。**

各疾病的阳性率差异巨大（冠心病 8.83% vs 糖尿病 10.88%），多数类基线准确率从 68% 到 91% 不等。本项目**从不以普通准确率作为验收标准**。

### 特征筛选

**方法：特征阶梯（Feature Ladder）**

从最小特征集开始，分层加入候选特征，每层用**相同的切分**、**8 个随机种子**做留出评估，取平均 AUC。**只有带来实质增益的特征才保留。**

以糖尿病 v3 为例：

| 特征集 | 特征数 | CV AUC | 增量 |
|--------|-------:|-------:|-----:|
| 核心风险因素（年龄/BMI/身高/体重/吸烟） | 5 | 0.7677 | — |
| **+ 高血压 + 高胆固醇 ← 采用** | **7** | **0.8124** | **+0.045** |
| + 冠心病 + 脑卒中 + 慢阻肺 | 10 | 0.8162 | +0.004 |

**结论：高血压与高胆固醇带来 +0.045 的实质提升**（它们是代谢综合征组分，标准糖尿病风险评分如 FINDRISC 即包含）；**而冠心病/脑卒中/慢阻肺仅 +0.004**，且它们是糖尿病的**并发症**（反向因果明显），故排除。

以**肺癌**为例，同样的方法得出了相反的结论——**只需要 3 个特征**：

| 特征集 | 特征数 | 平均 AUC |
|--------|-------:|---------:|
| 年龄 | 1 | 0.7927 |
| + 吸烟状态 | 2 | 0.8425 |
| **+ 慢阻肺 ← 采用** | **3** | **0.8706** |
| + 每日吸烟量 + BMI + 身高 + 体重 | 7 | 0.8681 |

每日吸烟量、BMI、身高、体重的增益均 **≤0.001**，故全部剔除——"三个问题"（年龄、吸烟状态、是否患慢阻肺）即可达到 AUC 0.87。

> **特征筛选的判据是实测增量，不是"教科书上写了这个危险因素"。**

### 准确率如何判别

这是本项目最想讲清楚的一点。**不同阳性率下，同一个指标的意义完全不同。**

**第一层：先看基线，再看模型。**

| 疾病 | 阳性率 | 多数类基线准确率 | 本模型普通准确率 | 结论 |
|------|-------:|-----------------:|-----------------:|------|
| 糖尿病 v3 | 10.88% | 89.12% | 0.6980 | **低于基线**——但这正是检出 80% 病例的代价 |
| 肺癌 | 0.412% | 99.59% | 0.8272 | **远低于基线**，普通准确率完全无参考价值 |
| 冠心病 | 8.83% | 91.17% | — | 同上 |

> "一律判为无病"就能拿到 99.59% 的准确率。**只报准确率的模型报告，可以直接忽略。**

**第二层：四个必须同时看的指标。**

| 指标 | 回答什么问题 | 适用场景 |
|------|--------------|----------|
| **AUC** | 排序能力——随机取一个阳性和一个阴性，阳性得分更高的概率 | 通用判别力 |
| **PR-AUC** | 在极稀有结局下，AUC 会因大量真阴性而虚高，PR-AUC 更敏感 | 阳性率 <1% 时必看 |
| **平衡准确率** | 敏感度与特异度的平均——类别不平衡下的"准确率" | 替代普通准确率 |
| **敏感度 / 特异度** | 具体操作点上的取舍 | 决定筛查用途 |

**肺癌的实例**：阳性率仅 0.412%，PR-AUC 基线只有 0.0041，本模型 0.0377——**提升 9.17 倍**。这个信息在 AUC 里是看不出来的。

**第三层：阈值不能默认 0.5。**

阳性率 10.88% 时，0.5 阈值会把几乎所有病例都判为阴性。本项目**一律在训练集上用交叉验证最大化平衡准确率来选阈值**（糖尿病 v3 选定 0.105，肺癌 0.0055）——**绝不接触测试集**。

**第四层：报告操作点表，让使用者自己选。**

以肺癌为例：

| 阈值 | 敏感度 | 特异度 | 精确率 | 判阳人群占比 | 用途 |
|-----:|-------:|-------:|-------:|-------------:|------|
| 0.002 | 0.896 | 0.641 | 1.02% | 36.1% | 筛查初筛（求高敏感度） |
| **0.0055（默认）** | **0.746** | **0.828** | **1.75%** | **17.5%** | 平衡准确率最优点 |
| 0.015 | 0.479 | 0.954 | 4.10% | 4.8% | 高风险提示（求高精确率） |

**第五层：验收线必须与疾病难度匹配，且要说明理由。**

本项目**不使用统一的 AUC 门槛**，每个疾病的验收线都有公开依据：

| 疾病 | 验收线 AUC | 依据 |
|------|-----------:|------|
| 肺癌 | ≥ 0.80 | 达到同系列慢病线 |
| 糖尿病 v3 | ≥ 0.80 | 同上 |
| 结直肠癌 | ≥ 0.75 | 阳性率仅 0.72%，稀有结局下性能天然受限 |
| 乳腺癌 | ≥ 0.72 | 队列限定女性、仅 4 个可用特征 |
| 甲状腺癌 | ≥ 0.60 | 最强三类危险因素（儿童期辐射、家族史、甲状腺结节）**NHIS 从未采集**；把全部 9 个可对齐候选特征都用上也仅 0.6440——**这是数据实测上限** |
| 高脂血症 | ≥ 0.78 | 标签为"检出依赖"（无症状疾病，取决于是否做过血脂检测）；48 组超参数扫描 AUC 区间仅 0.7917–0.7960，模型已饱和 |

> ⚠️ **高脂血症的验收线是事后设定的**（观察到模型饱和后），我们在其文档中**明确标注了这一点**，而非假装它是预先注册的阈值。这是本项目对方法学诚实的底线。

## 版本演进：我们改了什么，以及为什么

这个 repo 里的模型**不是一次做成的**。糖尿病有两个版本，它们的差异恰好说明了整个方法论是怎么演进的：

| | 糖尿病 v2 | 糖尿病 v3 |
|---|---|---|
| 数据集 | Pima Indians | **NHIS 2016–2025** |
| 样本量 | 768 | **291,945**（380 倍） |
| 阳性数 | 268 | **31,760**（118 倍） |
| 性别 | **仅女性** | 男女兼备 |
| 族裔 | **仅 Pima 印第安人** | 全族裔 |
| 特征 | 8（含血糖、胰岛素、皮褶厚度） | **7（全部为风险因素，无生化指标）** |
| 阈值 | 固定 0.5 | **训练集 CV 选定（0.105）** |
| 验收 | 普通准确率 ≥ 0.75 | **AUC ≥ 0.80 且平衡准确率 ≥ 0.70** |
| 评估 | 单次留出 | **3×5 折重复交叉验证** |

v2 保留在 repo 中，**作为方法论演进的历史记录**，也作为"小样本 + 人群受限数据集"的对照。我们**不推荐在实际场景中使用 v2**。

> 同理，**高血压模型（NHANES）也是早期版本**：它使用了 HbA1c、胆固醇、HDL、肌酐、尿酸等生化指标——这违反了后来确立的"不使用诊断性指标"原则。它保留是为了对照，其 AUC 0.8234 不应与 v3 系列直接比较。

## 已知局限

**我们把这个 section 放在显眼位置，因为它比结果更重要。**

**1. 全部标签均为自我报告。**
"曾被医生告知患有 X"混合了三件事：真实的疾病状态、**是否获得过诊断机会**、是否被医生告知。问卷无法分离这三者。**"低风险"不等于没有病——可能只是还没查过。**

**2. 横断面设计，是病例识别而非发病风险预测。**
NHIS/BRFSS 在单一时点询问"是否曾被医生告知患病"。模型预测的是**已患病的可能性**，不是"未来 N 年发病风险"。

**3. 反向因果无法排除。**
以肺癌为例：**已戒烟者的肺癌率（0.997%）高于当前吸烟者（0.681%）**。这不是"戒烟有害"，而是①因健康原因戒烟、②确诊后戒烟、③已戒烟者年龄更老且更常体检——三种效应叠加。同理，BMI 与肺癌负相关（更可能是肿瘤导致消瘦）。横断面设计无法分离。

**4. 检出偏倚。**
已确诊者与医疗系统接触更频繁，更易被查出其他疾病。糖尿病 v3 中高血压重要性高达 0.4684，其中既有真实的代谢综合征关联，也含检出偏倚成分。

**5. 树模型的特征重要性会被二值特征吸收。**
糖尿病 v3 模型中高血压重要性 0.4684，但去掉高血压/高胆固醇后，**年龄重要性从 0.068 跳到 0.630、BMI 从 0.034 跳到 0.221**。请勿把 gain 重要性当作"风险因素强度"排序。

**6. 人群适用性。**
全部基于**美国**人群。应用于其他国家（尤其是饮食结构、医疗可及性差异大的地区）需重新验证。

**7. 甲状腺癌与高脂血症模型判别力有限。**
AUC 0.6394 与 0.7956。前者受限于数据（最强危险因素未采集），后者受限于标签的检出依赖性。**请勿用于临床决策。**
