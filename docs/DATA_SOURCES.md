# 数据来源与选型调研 / Data Sources & Selection Survey

> 慢病模型使用的全部数据源、变量对齐细节、以及我们评估过但放弃的数据源及理由。

---

## 一、本项目使用的数据源

三个来源，**全部为美国政府公开数据（Public Domain），无需注册、无需数据使用协议**。

### 1. NHIS — 主数据源

| 项目 | 内容 |
|------|------|
| 全称 | National Health Interview Survey |
| 机构 | U.S. CDC / National Center for Health Statistics |
| 方式 | 面对面入户访谈（CAPI），全国代表性概率抽样 |
| 本项目窗口 | **2016–2025，共 10 个年度** |
| 人群 | 美国非机构化平民人口，≥18 岁，**男女兼备、不限种族** |
| 下载 | https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Datasets/NHIS/{年}/ |

**服务的模型**：糖尿病 v3（291,945 例）、高脂血症（291,295 例）

**为什么选 NHIS**：它是唯一能在 10 个年度内提供**一致口径**的吸烟、体格、共病变量的美国公开调查数据。

> 注意文件名大小写：**2019 年是 `Adult19csv.zip`（首字母大写）**，2020 起小写。

**跨问卷时代（2019 年改版）变量对齐**

| 语义 | 2016–2018 | 2019–2025 | 备注 |
|------|-----------|-----------|------|
| 年龄 | `AGE_P` | `AGEP_A` | 前者上限 85（85 = "≥85"），后者可达 99；**统一封顶 85** |
| 身高 | `AHEIGHT`（英寸） | `HEIGHTTC_A`（英寸） | 特殊码 96/97/98/99 → 缺失 |
| 体重 | `AWEIGHTP`（磅） | `WEIGHTLBTC_A`（磅） | 特殊码 996–998 → 缺失 |
| 吸烟状态 | `SMKSTAT2`（1–4 直接可用） | `SMKEV_A` + `SMKNOW_A` 合成 | 见下 |
| 高血压 | `HYPEV` | `HYPEV_A` | 1=是 2=否 7/9=缺失 |
| 高胆固醇 | `CHLEV` | `CHLEV_A` | 同上 |
| 糖尿病 | `DIBEV1` | `DIBEV_A` | 2016–18 有 "3=临界"，统一并入阴性 |

**吸烟状态合成规则**（2019+）：
`SMKEV_A=2` → 4=从不；`SMKEV_A=1 且 SMKNOW_A=1` → 1=每天；`=2` → 2=偶尔；`=3` → 3=已戒；`SMKNOW_A=5` 或 `SMKEV_A∈{7,8,9}` → 缺失。

**BMI 处理**：两个时代均**由身高体重现算**，避免口径不一致。

### 2. BRFSS — 大样本来源

| 项目 | 内容 |
|------|------|
| 全称 | Behavioral Risk Factor Surveillance System |
| 机构 | U.S. CDC |
| 方式 | 全美电话调查（固定电话 + 手机） |
| 本项目使用 | **2017 年**（445,872–448,666 条记录） |
| 人群 | 美国成人，年样本 40 万+ |
| 下载 | https://www.cdc.gov/brfss/annual_data/annual_2017.html |

**服务的模型**：冠心病（445,872）、慢阻肺（447,718）、脑卒中（448,666）

**为什么选 BRFSS**：样本量是 NHIS 的 1.5 倍，且 2017 年同时包含吸烟、饮酒、体力活动、一般健康状况、抑郁、共病等**全部所需变量**。

**为什么没用 BRFSS 做糖尿病/高脂血症**：BRFSS 与 NHIS 各有优劣，最终由**变量的跨年可得性**决定（见下）。

---

### 3. NHANES — 含体格检查与实验室检测

| 项目 | 内容 |
|------|------|
| 全称 | National Health and Nutrition Examination Survey |
| 机构 | U.S. CDC / NCHS |
| 方式 | 入户访谈 + **移动检查中心（MEC）体格检查与实验室检测** |
| 本项目使用 | **2017–2018 周期**（5,250 名成人） |
| 下载 | https://wwwn.cdc.gov/nchs/nhanes/ |

**服务的模型**：高血压（早期版本，见 [版本演进](#四版本演进)）

## 二、跨数据源一致性：我们实测的对齐情况

| 变量 | NHIS 2016–25 | BRFSS 2017 | NHANES 2017–18 |
|------|:------------:|:----------:|:--------------:|
| 年龄 | ✅ 全 10 年 | ✅ | ✅ |
| 身高 / 体重 / BMI | ✅ | ✅ | ✅（实测） |
| 吸烟状态 | ✅ 4 级 | ✅ | ✅ |
| 高血压（自报） | ✅ | ✅ | ✅（+ 实测血压） |
| 高胆固醇（自报） | ✅ | ✅ | ✅（+ 实测血脂） |
| 糖尿病（自报） | ✅ | ✅ | ✅（+ HbA1c） |
| 饮酒 | ❌ 2019 后无 | ✅ | ✅ |
| 体力活动 | ❌ 仅偶数年 | ✅ | ✅ |
| 一般健康状况 | ❌ | ✅ | ❌ |
| 抑郁 | ❌ | ✅ | ✅（PHQ-9） |
| **癌种** | ✅ | ❌ 仅皮肤/其他 | ⚠️ 例数极少 |
| 教育 / 收入 | ❌ **2016–18 无此变量** | ✅ | ✅ |

> **决定性的发现**：**2016–2018 的 NHIS 成人文件里根本没有 `EDUC` 和 `RATCAT`（收入）变量**——它们在 2019 年才引入。这直接排除了社会经济变量，也解释了为什么各模型的特征集不同。

## 三、评估过但放弃的数据源

**这一节通常不会出现在论文里，但对复现者最有价值。**

| 数据源 | 评估结论 | 否决理由（实测） |
|--------|----------|------------------|
| **NHIS 2011–2015** | ❌ 格式不可用 | 仅提供**定长 ASCII**，各年记录长度不同（827/1086/1021/1087/904）；布局 PDF **不含字节位置**。用 2016 年推导的布局对 2016 CSV 校验 100% 通过，但**无法跨年迁移** |
| **NHIS 教育 / 收入** | ❌ 无法跨年对齐 | 见上：2016–2018 无此变量 |
| **NHIS 体力活动** | ❌ 隔年轮换 | 2019 年改版后**仅偶数年（2020/2022/2024）**采集 |
| **NHIS 饮酒** | ❌ 缺失 | 2016–2018 有 `ALC*` 共 48 个变量；**2019 年后成人文件无任何饮酒变量** |
| **NHIS 家族史** | ❌ 仅 2 年且非目标 | 只有 `DIBREL`（糖尿病家族史），且**仅 2016–2017 有** |
| **SEER** | ❌ 无危险因素 | 全变量字典检索确认**零**吸烟/饮酒/BMI/家族史；且**无健康对照** |
| **BRFSS 做癌症** | ❌ 癌种不完整 | 直到 2022 年才加入 `CNCRTYP2`，且为**可选模块**，作答者仅 1.2–1.9 万人 |
| **NHANES 做稀有结局** | ❌ 例数不足 | 胃癌在全 11 周期（1999–2023）合计仅 **59 例** |
| **Kaggle 大数据集** | ⚠️ 逐个甄别 | 部分为**合成数据**。甄别方法见 [癌症 repo 的数据调研文档](https://github.com/bellawang2024/cancer-risk-models/blob/main/docs/DATA_AVAILABILITY.md) |

### 合成数据甄别清单

如果数据集满足以下多项特征，**极可能是生成的假数据**：

- [ ] 无来源、无引文、无伦理声明
- [ ] 各特征间相互独立（卡方检验全部不显著）
- [ ] 标签不可预测（AUC ≈ 0.5）
- [ ] 行数为"生成感"整数（100,000 / 212,354）
- [ ] 类别完全均衡
- [ ] 数值范围违反生理常识（如年龄均匀分布 20–80）
- [ ] 列名与某真实数据集完全重合但数值分布被替换
- [ ] 文件内自述 "synthetic"/"simulated"

> **最大的风险不是"效果差"，而是 AUC ≈ 0.5 会让人误判特征无预测力**，进而放弃一个本来可行的方向。

## 四、版本演进

本 repo 的模型**不是一次做成的**，早期版本的方法论与后期不同：

| | 早期版本 | 后期版本（推荐） |
|---|---|---|
| 代表模型 | 糖尿病 v2（Pima）、高血压（NHANES） | 糖尿病 v3、高脂血症、冠心病等 |
| 数据规模 | 768 / 5,250 | 29 万 – 45 万 |
| 人群代表性 | ⚠️ 受限（见下） | 全人群 |
| 特征 | 含生化指标 | **仅风险因素** |
| 阈值 | 固定 0.5 | 训练集 CV 选定 |
| 验收 | 普通准确率 | AUC + 平衡准确率 |
| 评估 | 单次留出 | 3×5 折重复交叉验证 |

**⚠️ Pima 数据集的人群限制（必须知道）**

其官方原始文件写明：

> *"all patients here are females at least 21 years old of Pima Indian heritage"*

——**仅女性、≥21 岁、仅 Pima 印第安人**，共 768 例，数据中**根本没有性别列**。用它训练的模型**不可外推到男性或其他族裔**。

**⚠️ 高血压模型（NHANES）的生化指标问题**

它使用了 HbA1c、胆固醇、HDL、肌酐、尿酸等指标。其中 **HbA1c 与血脂本身即诊断依据**，违反了后期确立的"不使用诊断性指标"原则。其 AUC 0.8234 **不可与 v3 系列直接比较**。

两个早期版本**保留作为方法论演进的历史记录**，但我们**不推荐在实际场景中使用**。

## 五、数据许可与合规

| 数据源 | 许可 | 是否需要申请 |
|--------|------|--------------|
| NHIS | 美国政府公开数据（Public Domain） | ❌ 不需要 |
| BRFSS | 同上 | ❌ 不需要 |
| NHANES | 同上 | ❌ 不需要 |

**本 repo 不重新分发原始数据**——`scripts/fetch_data.py` 从 CDC 官方地址下载，并逐文件校验 SHA256。

**引用要求**：使用本项目时请同时引用原始调查：

- National Center for Health Statistics. *National Health Interview Survey, 2016–2025.*
- Centers for Disease Control and Prevention. *Behavioral Risk Factor Surveillance System, 2017.*
- National Center for Health Statistics. *National Health and Nutrition Examination Survey, 2017–2018.*
