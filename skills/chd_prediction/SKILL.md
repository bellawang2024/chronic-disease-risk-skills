# 冠心病（CHD）风险预测模型

## 概述

基于**真实、可追溯、全人群**的公开权威数据集 BRFSS 2017（美国 CDC），
使用 XGBoost 训练冠心病/心肌梗死风险二分类模型。本 skill 内置**已训练好的推理模型**，
解压即可预测，无需重新训练。

| 项目 | 值 |
|------|-----|
| 任务 | 二分类（是否曾被医生告知患有冠心病 CHD 或心肌梗死 MI） |
| 算法 | XGBoost (`xgboost.XGBClassifier`) |
| 数据集 | BRFSS 2017（美国 CDC 行为风险因素监测系统） |
| **目标人群** | **美国 50 州及属地的成年居民（全人群抽样，不限性别、种族）** |
| 原始记录 | 450,016 → 建模队列 **445,872** |
| 特征数 | **15**（年龄、体格、生活方式、疾病史） |
| 阳性事件 | **39,357**（患病率 8.83%） |
| 划分 | test_size=0.2, random_state=42, stratify=True → 356,697 训练 / 89,175 测试 |
| 决策阈值 | **0.08**（由训练集交叉验证选定，不是 0.5） |

## ⚠️ 关于"准确率"的重要说明

本任务阳性率仅 **8.83%**，属于**不平衡分类**问题：

- **多数类基线准确率 = 91.17%**（即"全部预测为无冠心病"就能得到 91.17% 的准确率）
- 本模型在留出测试集上的**普通准确率为 0.7120，反而低于该基线**

这不是模型失败，而是**准确率在罕见结局任务上是失效指标**的典型表现
（accuracy paradox）。若强行把准确率刷到 91% 以上，只需把阈值调高、
几乎不预测阳性即可 —— 但那样的模型毫无筛查价值。

因此本 skill 的验收标准采用**不平衡分类的规范指标**：

| 指标 | 含义 |
|------|------|
| **AUC** | 排序能力，与阈值无关，不平衡任务的首选指标 |
| **平衡准确率** | (敏感度 + 特异度) / 2，对类别不平衡不敏感 |
| **PR-AUC** | 精确率-召回率曲线下面积，基线 = 患病率 0.0883 |
| 敏感度 / 特异度 | 在选定阈值下分别报告，便于按场景取舍 |

## 不使用人群划分属性（结构性保证）

**性别（`SEX`）与种族（`_RACE`）在数据构建阶段完全没有被提取**，
未出现在内置 CSV 中，因此模型在结构上不可能使用任何人群划分属性 ——

## 功能

### 1. 预测个体风险（模型已内置，无需先训练）

需提供 **6 项主要临床指标**：

```bash
python scripts/predict.py --age 62 --bmi 29.5 --smoker 3 --diabetes 0 \
    --hypertension 1 --high-chol 1
```

| 参数 | 描述 | 取值 | 是否必需 |
|------|------|------|----------|
| `--age` | 年龄 | 18–80 岁（80 表示 ≥80） | **必需** |
| `--bmi` | BMI 体重指数 | 10–90 | **必需** |
| `--smoker` | 吸烟状态 | 1=每天 2=偶尔 3=已戒 4=从不 | **必需** |
| `--diabetes` | 糖尿病 | 1=有 0=无 | **必需** |
| `--hypertension` | 高血压（医生告知） | 1=有 0=无 | **必需** |
| `--high-chol` | 高胆固醇（医生告知） | 1=有 0=无 | **必需** |
| `--gen-health` | 自评健康状况 | 1=优 2=良 3=一般 4=差 5=很差 | 可选 |
| `--exercise` | 休闲运动（近 30 天） | 1=有 0=无 | 可选 |
| `--copd` | 慢阻肺/肺气肿 | 1=有 0=无 | 可选 |
| `--depression` | 抑郁障碍 | 1=有 0=无 | 可选 |
| `--height` / `--weight` | 身高/体重 | cm / kg | 可选 |
| `--education` | 教育程度 | 1–6 | 可选 |
| `--income` | 家庭年收入档 | 1–8 | 可选 |
| `--drinks-wk` | 每周饮酒量 | 杯/周 | 可选 |

> **为什么主要风险因素必须显式提供？**
> 若允许它们被中位数插补，等价于假设"该患者没有高血压/没有高胆固醇"，
> 会**系统性低估风险**。因此这 6 项作为必填项校验。
> 次要指标未提供时用训练中位数插补，并在输出的 `imputed_features` 中列出。

## 决策阈值为什么是 0.08

在本任务中阳性率仅 8.83%，模型输出的概率整体偏低（测试集概率中位数 0.037），
固定阈值 0.5 会导致敏感度只有 **0.076**（几乎不报警），模型完全不可用。

因此阈值由**训练集交叉验证**在 0.02–0.80 范围内最大化平衡准确率选出，
得到 **0.08**，且**未使用测试集**：

| 阈值 | AUC | 平衡准确率 | 敏感度 | 特异度 |
|------|-----|-----------|--------|--------|
| 0.50（错误默认） | 0.8479 | 0.5355 | 0.0767 | 0.9942 |
| **0.08（选定）** | **0.8479** | **0.7693** | **0.8389** | **0.6997** |

> **解读警告（检出偏倚）**：高血压、高胆固醇、自评健康排在前列，除真实的病理关联外，
> 还包含**反向因果/检出偏倚** —— 已确诊冠心病的人会被反复检查，
> 从而更可能被查出高血压与高胆固醇，也更可能自评健康较差。
> 因此这三项的重要性**被高估**，不可直接当作"因果风险因素强度"解读。

## 注意事项

1. **横断面数据，不是发病风险预测**：BRFSS 在单一时点询问"是否曾被医生告知患病"，
   因此本模型预测的是**已患病的可能性（病例识别）**，而**不是**"未来 N 年发病风险"。
   它与 Framingham 这类前瞻性队列风险模型的含义不同，**不可混用**。
2. **检出偏倚**：见上文特征重要性解读警告。
3. **自我报告**：风险因素与结局均为自报，未经体检或病历核实，存在回忆与报告偏倚。
4. **准确率不适用**：见开头"关于准确率的重要说明"。
5. **人群适用性**：数据来自**美国**成年居民（2017 年），迁移到其他国家和地区需重新验证。
6. **临床决策**：本模型仅作为健康风险筛查的辅助参考与教学演示，
   **不能替代专业医生的诊断**。
