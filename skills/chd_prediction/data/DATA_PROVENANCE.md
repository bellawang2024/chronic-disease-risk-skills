# 数据溯源说明（DATA PROVENANCE）

本 skill 使用 **BRFSS 2017（美国行为风险因素监测系统）**，
来源权威、可逐字节追溯，且**目标人群为全人群，模型不使用性别、种族等任何人群划分属性**。

## 1. 数据来源

| 项目 | 内容 |
|------|------|
| 调查项目 | BRFSS (Behavioral Risk Factor Surveillance System) |
| 执行机构 | U.S. Centers for Disease Control and Prevention (CDC) |
| 调查年份 | 2017 |
| 目标人群 | **美国 50 州及属地的成年居民**（≥18 岁），不限性别、种族、地区、收入 |
| 调查方式 | 全美随机电话调查（固定电话 + 手机），全球规模最大的持续性健康电话调查 |
| 原始记录数 | **450,016** |
| 官方页面 | https://www.cdc.gov/brfss/annual_data/annual_2017.html |
| 数据下载 | https://www.cdc.gov/brfss/annual_data/2017/files/LLCP2017XPT.zip |
| 数据许可 | 美国政府公开数据（Public Domain），可自由使用 |

### 为什么选 BRFSS

1. **全人群**：覆盖全美 50 州及属地的成年居民，是"全人群"意义上的抽样调查，
   而非某个性别、族裔或临床亚组。
2. **样本量充足**：原始 45 万条记录，建模队列 44.6 万条，
   阳性事件 39,357 例 —— 冠心病属相对少见结局（患病率 8.83%），
   充足的事件数是获得稳定评估指标的前提。
3. **可追溯**：单一官方压缩包，可通过 SHA256 逐字节校验。

### 关于 CDC 压缩包的两个坑（脚本已处理）

1. **文件名含尾随空格**：解压后的文件名为 `LLCP2017.XPT `（末尾有一个空格），
   直接按 `LLCP2017.XPT` 打开会报"文件不存在"。
2. **体积较大**：XPT 解压后约 **1.29 GB**，解析约需 50 秒与约 2 GB 内存。

## 3. 建模队列构建规则（完全可复现）

1. **读取**：解析 BRFSS 2017 原始 XPT（450,016 条记录 × 358 列）。
2. **纳入**：`_MICHD` 有作答记录者（剔除 4,144 条无作答）。
3. **结果**：**445,872** 条，其中阳性（有冠心病/心梗）**39,357** 条，
   患病率 **8.83%**。

### 标签定义

`_MICHD` —— CDC **官方派生变量**："曾被医生告知患有冠心病（CHD）或心肌梗死（MI）"
（Respondents that have ever reported having coronary heart disease (CHD)
or myocardial infarction (MI)）。编码 1 = 是，2 = 否。

原始问卷来源：`CVDCRHD4`（冠心病）+ `CVDINFR4`（心肌梗死）。

### 特征列表（15 个）

| 列名 | 含义 | 来源变量 | 编码 | 缺失数 |
|------|------|----------|------|--------|

| weight_kg | 体重 | `WTKG3` | `WTKG3 ÷ 100` | 29,461 |

| high_chol | 高胆固醇（医生告知） | `_RFCHOL1` | **2=是 → 1；1=否 → 0** | 50,864 |

## 4. 编码方向核对（重要）

BRFSS 中不同变量的 1/2 含义**并不一致**，若统一按"1=是"处理会导致特征方向反转。
本次构建对每个变量都做了显式核对，方法是用**原始来源变量做交叉表**验证：

| 派生变量 | 交叉核对依据 | 结论 |
|----------|--------------|------|
| `_RFHYPE5` | 与 `BPHIGH4`（1=Yes）交叉表：`BPHIGH4=1` 全部对应 `_RFHYPE5=2` | 1=否，2=是 |
| `_RFCHOL1` | 与 `TOLDHI2`（1=Yes）交叉表：`TOLDHI2=1` 全部对应 `_RFCHOL1=2` | 1=否，2=是 |
| `_TOTINDA` | 均值年龄：取值 1 → 54.2 岁（较年轻，符合"有运动"） | 1=是 |
| `ADDEPEV2` | 均值年龄：取值 1 → 53.1 岁 | 1=是 |
| `CHCCOPD1` | 均值年龄：取值 1 → 63.3 岁（较年长，符合"有 COPD"） | 1=是 |

另外还做了**临床合理性自检**（阳性率应落在已知流行病学区间）：

| 指标 | 本数据集阳性率 | 美国成人已知水平 |
|------|----------------|------------------|
| 高血压（自报） | 40.16% | 约 35%–40% |
| 高胆固醇（自报） | 39.17% | 约 30%–40% |
| 糖尿病（自报） | 13.35% | 约 12%–14% |
| 当前吸烟 | 14.07% | 约 14%–17% |
| 有休闲运动 | 72.51% | 约 70%–75% |
| 慢阻肺 | 8.28% | 约 6%–9% |
| 抑郁障碍 | 19.83% | 约 18%–20% |

以及方向自检：高血压阳性者平均年龄 63.0 岁 vs 阴性者 49.6 岁；
高胆固醇阳性者 62.6 岁 vs 阴性者 53.0 岁 —— 均符合"随年龄上升"的临床预期。

### 关于 `_DRNKWEK` 的两个陷阱

1. **缩放**：该变量为"杯/周 × 100"，直接使用会得到中位数 23 这类不合理值；
   除以 100 后中位数为 0.23 杯/周、P90 为 7.00 杯/周，符合实际。
2. **零值编码**：非饮酒者并非编码为 0，而是一个**极小非规格化浮点数**
   （约 `5.4e-79`，SAS 传输格式的 0 表示）。脚本中按 `< 0.005` 归零处理。

## 5. 不使用人群划分属性（结构性保证）

**性别（`SEX`）与种族（`_RACE`）在数据构建阶段完全没有被提取**，
未出现在 `data/coronary_heart_disease_brfss.csv` 中，
因此随附模型在结构上不可能使用任何人群划分属性，而非仅在训练时忽略。

特征全部为年龄、体格、生活方式与疾病史等**与人群归属无关**的指标。

## 6. 缺失值

派生 CSV 保留原始缺失（空值），由训练/推理时的
`SimpleImputer(strategy="median")` 按训练中位数插补。
推理时**主要临床风险因素必须显式提供**（见下），仅次要指标允许插补 ——
否则等于假设患者"没有该风险因素"，会系统性低估风险。

主要风险因素（必须提供）：`age, bmi, smoker, diabetes, hypertension, high_chol`
次要指标（可省略并插补）：`height_cm, weight_kg, gen_health, exercise, education,
income, drinks_wk, depression, copd`

插补中位数完整记录在 `models/model_metadata.json` 的
`preprocessing.imputer_statistics`。

## 8. 使用限制与声明（重要）

1. **横断面数据，不是前瞻性风险预测**：BRFSS 在单一时点询问"是否曾被医生告知
   患有冠心病/心梗"，因此本模型预测的是**已患病的可能性（病例识别）**，
   而非"未来 10 年发病风险"。它与 Framingham 这类前瞻性队列风险模型的
   含义不同，不可混用。
2. **检出偏倚 / 反向因果**：已确诊冠心病的人更可能被反复检查、从而被查出高血压与
   高胆固醇，也更可能自评健康较差。这会使"高血压""高胆固醇""自评健康"的
   重要性被高估（三者恰为重要性前四位中的三个）。解读特征重要性时必须考虑这一点。
3. **自我报告**：风险因素与结局均为受访者自报，未经体检或病历核实，
   存在回忆偏倚与报告偏倚。
4. **准确率不是有效指标**：本任务阳性率仅 8.83%，多数类基线准确率即有 **91.17%**。
   请以 AUC、平衡准确率、敏感度/特异度为准（见 `SKILL.md`）。
5. **人群适用性**：模型基于**美国**成年居民数据（2017 年），
   应用于其他国家和地区人群时需重新验证。
6. **临床用途**：本模型仅用于健康风险筛查的辅助参考与教学演示，
   **不能替代专业医生的诊断**。
