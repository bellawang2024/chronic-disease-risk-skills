# 高脂血症（高胆固醇）风险预测模型（全人群）

## 概述

基于**真实、可追溯、全人群**的公开权威数据集 NHIS 2016–2025（美国 CDC/NCHS），
使用 XGBoost 训练高脂血症风险二分类模型。本 skill 内置**已训练好的推理模型**，
解压即可预测，**无需重新训练**。

| 项目 | 内容 |
|------|------|
| 数据来源 | **NHIS 2016–2025**（美国 CDC/NCHS 全国住户抽样，10 个年度） |
| 目标人群 | **美国非机构化平民人口（全人群）**，男女兼备、不限种族 |
| 样本数 | **291,295** 名成人（≥18 岁） |
| 阳性数 | **91,932** 例（患病率 **31.56%**） |
| 特征数 | **7 项**（年龄、BMI、身高、体重、吸烟、高血压、糖尿病） |
| 模型 | XGBoost 二分类 |
| 留出测试集 | **AUC 0.7960**，**平衡准确率 0.7263**（58,259 样本） |
| 3×5 折交叉验证 | **AUC 0.7956 ± 0.0020**，**平衡准确率 0.7251 ± 0.0015** |
| 决策阈值 | **0.305**（由训练集交叉验证选定，不是 0.5） |
| 人群划分属性 | **未使用**（性别/种族在构建阶段即未提取） |

## ⚠️ 三个必须先知道的限制

### 1. 不含任何血脂检验值

本模型**没有**总胆固醇、LDL-C、HDL-C、甘油三酯等任何检验指标。
原因是**这些指标本身即高脂血症的诊断依据**，用它们预测高脂血症近乎循环论证
（同系列糖尿病 v3 不纳入 HbA1c/血糖，是同一逻辑）。

**→ 本模型只做风险分层，确诊必须依靠血脂检测。**

### 2. 标签是「检出依赖」的（性能上限的主要来源）

高脂血症**无症状**。要被记录为「曾被医生告知高胆固醇」，前提是
**先做过血脂检测**、结果异常、并被医生告知。

因此本标签同时编码了三件事：真实血脂水平、**是否获得过血脂检测**
（取决于医疗可及性、保险、就医频率）、是否被医生告知。

问卷无法把后两项与第一项分离。这是本模型 AUC 上不去的主因之一。

### 3. 标签只覆盖胆固醇，不覆盖甘油三酯

NHIS **只有** `CHLEV` 这一个血脂变量，**没有任何甘油三酯变量**（已核验 10 个年度）。
因此标签严格来说是「曾被告知**高胆固醇**」，是**高脂血症的胆固醇部分**，
**不包含「单纯高甘油三酯血症」**。以「高脂血症」泛指时须注意此口径差异。

## ⚠️ 为何本模型的验收线低于同系列慢病线

同系列慢病 skill 的线是 **AUC ≥ 0.80 / 平衡准确率 ≥ 0.70**。
本 skill 定为 **AUC ≥ 0.78 / 平衡准确率 ≥ 0.68**。

| 指标 | 本模型实测 | 本任务线 | 同系列慢病线 | 结论 |
|------|-----------|----------|--------------|------|
| 交叉验证 AUC | **0.7956 ± 0.0020** | ≥ 0.78 ✓ | ≥ 0.80 | **未达**（差 0.0044） |
| 交叉验证 平衡准确率 | **0.7251 ± 0.0015** | ≥ 0.68 ✓ | ≥ 0.70 | **达到** |

**下调的三条依据：**

1. **标签检出依赖**（见上文第 2 点）。同系列其他疾病的标签虽也是自报，
   但糖尿病/高血压有更明确的检测触发路径；血脂检测在人群中是**选择性**进行的。
2. **最强决定因素不可得**：血脂值本身（循环）、**高胆固醇家族史**
   （NHIS 从未询问）、膳食饱和脂肪（未一致采集）、体力活动（2019 后仅偶数年）、
   社会经济地位（**2016–2018 成人文件根本没有教育/收入变量**）、遗传因素
   ——高脂血症最核心的几类决定因素，本数据一个都用不了。
3. **模型已饱和，瓶颈在特征而非模型容量**：48 组超参数扫描
   （`max_depth` 3–6 × `n_estimators` {400,800} × `learning_rate` {0.05,0.1}
   × `min_child_weight` {10,30,60}）的 AUC 区间仅 **0.7917–0.7960**。
   换任何超参数都推不过 0.80，除非引入反向因果的特征。

> ⚠️ **方法学声明：0.78 这条线是在观察到模型饱和于 0.796 之后设定的，
> 属事后设定，并非预先注册的阈值。** 上述三条依据独立于实测结果可核验，
> 但读者应知道这一时序。

## 为什么是这 7 个特征（实测依据）

候选特征按 **8 个随机种子**做留出评估，取平均 AUC：

| 特征集 | 特征数 | AUC | 增量 |
|--------|--------|-----|------|
| 年龄 | 1 | 0.7483 | — |
| + BMI | 2 | 0.7602 | +0.012 |
| + 身高/体重 | 4 | 0.7616 | +0.001 |
| + 吸烟 | 5 | 0.7638 | +0.002 |
| **+ 高血压 + 糖尿病 ← 本模型** | **7** | **0.7959** | **+0.032** |
| + 冠心病/脑卒中/慢阻肺 | 10 | 0.8004 | +0.0045 |

- **高血压/糖尿病保留**：它们是**代谢综合征组分**，与高脂血症共享上游病因
  （肥胖、胰岛素抵抗），贡献 +0.032 AUC，是最大的单一增益。
- **身高/体重/吸烟保留**：合计仅 +0.0017，但保留以与同系列 skill 的
  核心风险因素块（年龄/BMI/身高/体重/吸烟 + 2 个代谢组分）保持一致，
  使跨疾病比较有意义。
- **冠心病/脑卒中/慢阻肺排除**：它们是高脂血症的**下游后果**（ASCVD），
  反向因果明显；虽然加入能到 0.8004，仍按糖尿病 v3 的先例排除。

### 被排除的变量（重要）

| 变量 | 为何排除 |
|------|----------|
| 血脂检验值 | **本身即诊断依据 → 循环论证** |
| `CHLMED_A`/`CHLMDEV2`（降脂药史） | **服药即意味着已确诊 → 循环信息** |
| `CHL12M_A`（近 12 月查血脂） | 检测行为，与标签定义直接重叠 |
| `CHLYR`（被告知年份） | 仅阳性者有值，泄漏标签 |
| 高胆固醇家族史 | **NHIS 从未询问** |
| 膳食 / 体力活动 / 饮酒 | 未一致采集（体力活动 2019 后仅偶数年；饮酒 2019 后无） |
| 教育 / 收入 | **2016–2018 成人文件根本没有这两个变量**（2019 才引入）；且主要为医疗可及性代理，会强化检出偏倚 |

## 不使用人群划分属性（结构性保证）

NHIS 中的 `SEX`/`SEX_A` 与 `RACE*`/`RACERPI2` 等变量
**在数据构建阶段即未提取**（见 `scripts/fetch_data.py` 的 `OUTPUT_COLUMNS`）。
这是**结构性保证**，而非训练时的口头约定——模型文件里根本不存在这些字段。

## 功能

### 1. 预测个体风险（模型已内置，无需先训练）

**3 项核心指标必需**，另有 4 项可选：

```bash
python scripts/predict.py --age 55 --bmi 28.5 --smoker 4 --height 170 --weight 82 \
    --hypertension 1 --diabetes 0
```

| 参数 | 描述 | 取值 | 是否必需 |
|------|------|------|----------|
| `--age` | 年龄 | 18–85 岁 | **必需** |
| `--bmi` | BMI 体重指数 | 10–90 | **必需** |
| `--smoker` | 吸烟状态 | 1=每天 2=偶尔 3=已戒 4=从不 | **必需** |
| `--hypertension` | 高血压（医生告知） | 1=有 0=无 | 可选，但**强烈建议** |
| `--diabetes` | 糖尿病（医生告知） | 1=有 0=无 | 可选，但**强烈建议** |
| `--height` | 身高 | 120–230 cm | 可选 |
| `--weight` | 体重 | 30–300 kg | 可选 |
| `--threshold` | 自定义判定阈值 | 见操作点表 | 可选 |

> **强烈建议提供高血压与糖尿病**：它们是本模型最重要的两个特征
> （重要性 0.532 / 0.182，单变量 2.92 / 2.41 倍）。缺失时会用中位数
> （=0，「无该病」）插补，**系统性低估风险**；脚本会显式给出警告。

## 特征重要性（实测）与解读警告

| 特征 | 重要性 |
|------|--------|
| hypertension（高血压） | 0.5319 |
| age（年龄） | 0.2468 |
| diabetes（糖尿病） | 0.1824 |
| smoker（吸烟状态） | 0.0173 |
| bmi（BMI） | 0.0127 |
| height_cm（身高） | 0.0045 |
| weight_kg（体重） | 0.0044 |

> ⚠️ **请勿把上表当作「风险因素强度」排序**：
>
> 1. **树模型 gain 偏向二值特征**（高血压/糖尿病只需一次分裂即可分开人群）。
>    去掉这两项后：年龄 **0.247 → 0.797**、BMI **0.013 → 0.066**、
>    吸烟 **0.017 → 0.103**。
> 2. **按单变量梯度看，年龄才是最强因素**（人群基线 31.56%）：
>    - 年龄 18–30 岁 **5.09%** → 70–85 岁 **53.86%**（**11 倍**）
>    - BMI <20 **17.09%** → ≥35 **38.64%**（2.3 倍）
>    - 高血压 无 **18.54%** → 有 **54.19%**（2.92 倍）
>    - 糖尿病 无 **27.15%** → 有 **65.42%**（2.41 倍）
> 3. **【反直觉】已戒烟者的高胆固醇率（42.17%）高于从不吸烟者（27.52%）。**
>    这不是「戒烟有害」，而是因健康原因戒烟、以及确诊后改变生活方式者
>    更可能已被检测（反向因果 + 检出偏倚）。
> 4. **高血压/糖尿病与高脂血症同属代谢综合征组分**，共享上游病因
>    （肥胖、胰岛素抵抗），并非单向因果。但高脂血症**无症状**，
>    「被告知」的前提是先做过血脂检测；而常因高血压/糖尿病就诊者，
>    被查血脂的机会显著更高——因此这 2.92 / 2.41 倍中同时含
>    **真实的代谢关联**与**检出偏倚**，本设计无法分离。

## 推理模型工件

```
models/
├── hyperlipidemia_xgb_model.json   # XGBoost 原生格式（推荐）
├── hyperlipidemia_xgb_model.ubj    # 二进制备份
├── imputer.joblib                  # 中位数插补参数

```

> 推理路径只需 **xgboost + numpy**。若 `joblib` 不可用，
> `predict.py` 会自动改用 `model_metadata.json` 中的 `imputer_statistics`。

## 注意事项

1. **不含血脂检验值**：本模型只用于风险分层。确诊必须依靠血脂检测，
   请遵医嘱。本项目**不替代**任何血液检查。
2. **标签是检出依赖的**：高脂血症无症状，「被告知」的前提是先做过血脂检测。
   模型部分反映的是**检测机会 / 医疗可及性**，不是纯生物学风险。
   **「低风险」不等于没有高脂血症**——可能只是还没查过。
3. **标签只覆盖胆固醇**：不含单纯高甘油三酯血症。
4. **这是病例识别模型，不是发病风险预测**：标签为「曾被告知」，即现患/曾患。
5. **性能低于同系列慢病线**：AUC 0.7956，差 0.80 线 0.0044；
   平衡准确率 0.7251 达标。原因与证据见「为何低于慢病线」一节。
6. **普通准确率参考价值有限**：多数类基线 68.44%。
7. **人群适用性**：基于美国成人（2016–2025 年）。血脂检测习惯、
   医疗可及性与饮食结构不同的人群需重新验证。
8. **本技能仅供学习研究使用。**
