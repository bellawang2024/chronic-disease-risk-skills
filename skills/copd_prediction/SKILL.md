# 慢性阻塞性肺疾病（COPD）风险预测模型

## 概述

基于**真实、可追溯、全人群**的公开权威数据集 BRFSS 2017（美国 CDC），
使用 XGBoost 训练 COPD 风险二分类模型。本 skill 内置**已训练好的推理模型**，
解压即可预测，无需重新训练。

| 项目 | 值 |
|------|-----|
| 任务 | 二分类（是否曾被医生告知患有 COPD、肺气肿或慢性支气管炎） |
| 算法 | XGBoost (`xgboost.XGBClassifier`) |
| 数据集 | BRFSS 2017（美国 CDC 行为风险因素监测系统） |
| **目标人群** | **美国 50 州及属地的成年居民（全人群抽样，不限性别、种族）** |
| 原始记录 | 450,016 → 建模队列 **447,718** |
| 特征数 | **14**（年龄、体格、生活方式、疾病史） |
| 阳性事件 | **37,577**（患病率 8.39%） |
| 划分 | test_size=0.2, random_state=42, stratify=True → 358,174 训练 / 89,544 测试 |
| 决策阈值 | **0.09**（由训练集交叉验证选定，不是 0.5） |

## ⚠️ 关于"准确率"的重要说明

本任务阳性率仅 **8.39%**，属于**不平衡分类**问题：

- **多数类基线准确率 = 91.61%**（即"全部预测为无 COPD"就能得到 91.61% 的准确率）
- 本模型在留出测试集上的**普通准确率为 0.7689，反而低于该基线**

这不是模型失败，而是**准确率在相对少见结局任务上失效**的典型表现
（accuracy paradox）。若强行把准确率刷到 91% 以上，只需把阈值调高、
几乎不预测阳性即可 —— 但那样的模型毫无筛查价值。

因此本 skill 的验收标准采用**不平衡分类的规范指标**：

| 指标 | 含义 |
|------|------|
| **AUC** | 排序能力，与阈值无关，不平衡任务的首选指标 |
| **平衡准确率** | (敏感度 + 特异度) / 2，对类别不平衡不敏感 |
| **PR-AUC** | 精确率-召回率曲线下面积，基线 = 患病率 0.0839 |
| 敏感度 / 特异度 | 在选定阈值下分别报告，便于按场景取舍 |

## 不使用人群划分属性（结构性保证）

**性别（`SEX`）与种族（`_RACE`）在数据构建阶段完全没有被提取**，
未出现在内置 CSV 中，因此模型在结构上不可能使用任何人群划分属性 ——
这不是"训练时忽略"，而是数据里根本没有。

**同时排除了标签泄漏变量**：`COPDCOGH`（慢性支气管炎）、`COPFLEM`（肺气肿）、
`COPDBRTH`、`COPDBTST`、`COPDSMOK` 均为**仅对 COPD 患者追问的后续问题**，
若作为特征将造成严重泄漏。`ASTHMA3`（哮喘）属同类呼吸系统疾病，亦已排除，
以保持"纯风险因素 → COPD"的语义。

## 功能

### 1. 预测个体风险（模型已内置，无需先训练）

需提供 **6 项主要临床指标**：

```bash
python scripts/predict.py --age 62 --bmi 26.5 --smoker 1 --diabetes 0 \
    --hypertension 1 --high-chol 0
```

| 参数 | 描述 | 取值 | 是否必需 |
|------|------|------|----------|
| `--age` | 年龄 | 18–80 岁（80 表示 ≥80） | **必需** |
| `--bmi` | BMI 体重指数 | 10–90 | **必需** |
| `--smoker` | 吸烟状态 | 1=每天 2=偶尔 3=已戒 4=从不 | **必需** |
| `--diabetes` | 糖尿病 | 1=有 0=无 | **必需** |
| `--hypertension` | 高血压（医生告知） | 1=有 0=无 | **必需** |
| `--high-chol` | 高胆固醇（医生告知） | 1=有 0=无 | **必需** |
| `--gen-health` | 自评健康状况 | 1=优 2=良 3=一般 4=差 5=很差 | 可选 |
| `--exercise` | 休闲运动（近 30 天） | 1=有 0=无 | 可选 |
| `--depression` | 抑郁障碍 | 1=有 0=无 | 可选 |
| `--height` / `--weight` | 身高/体重 | cm / kg | 可选 |
| `--education` | 教育程度 | 1–6 | 可选 |
| `--income` | 家庭年收入档 | 1–8 | 可选 |
| `--drinks-wk` | 每周饮酒量 | 杯/周 | 可选 |

> **为什么主要风险因素必须显式提供？**
> 若允许它们被中位数插补，等价于假设"该患者不吸烟/没有高血压"，
> 会**系统性低估风险**。因此这 6 项作为必填项校验。
> 次要指标未提供时用训练中位数插补，并在输出的 `imputed_features` 中列出。

## 决策阈值为什么是 0.09

本任务阳性率仅 8.39%，模型输出的概率整体偏低，固定阈值 0.5 会导致
**敏感度仅 0.1143**（几乎不报警），模型基本不可用：

| 阈值 | AUC | 平衡准确率 | 敏感度 | 特异度 | F1 |
|------|-----|-----------|--------|--------|-----|
| 0.50（错误默认） | 0.8389 | 0.5531 | 0.1143 | 0.9919 | 0.1901 |
| **0.09（选定）** | **0.8389** | **0.7609** | **0.7513** | **0.7705** | **0.3531** |

阈值由**训练集交叉验证**在 0.01–0.80 范围内最大化平衡准确率选出，
得到 **0.09**，且**未使用测试集**。

> 2. **自评健康第 1（0.3961）** —— 其重要性主要来自**反向因果**：

>    升至 13.20%），原因是其效应部分被**吸烟状态等中介变量吸收**
>    （年龄 → 累积吸烟量 → COPD）。

## 注意事项

1. **确诊依赖肺功能检查**：COPD 的临床确诊必须依靠**肺功能检查**
   （吸入支气管舒张剂后 FEV1/FVC < 0.70）。本模型仅基于问卷与常规指标，
   **不能用于确诊**，只能提示"是否值得去做肺功能检查"。
2. **横断面数据，不是发病风险预测**：BRFSS 问的是"是否曾被医生告知患病"，
   本模型做的是**病例识别（已患病可能性）**，**不是**"未来 N 年发病风险"。
3. **存在大量未诊断人群**：COPD 在人群中诊断率偏低，本模型的标签是"曾被医生告知"，
   因此"阴性"不等于没有 COPD，只表示未被告知过。
4. **自报数据**：风险因素与结局均为受访者自报，存在回忆与报告偏倚。
5. **准确率不适用**：见开头"关于准确率的重要说明"。
6. **人群适用性**：数据来自**美国**成年居民（2017 年），迁移到其他国家和地区需重新验证。
7. **临床决策**：本模型仅作为健康风险筛查的辅助参考与教学演示，
   **不能替代专业医生的诊断与肺功能检查**。
