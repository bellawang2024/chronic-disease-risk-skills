# 糖尿病风险预测 Skill v3（diabetes_prediction_v3，全人群）

基于**真实权威全人群数据集** NHIS 2016–2025（美国 CDC/NCHS 全国住户抽样，10 个年度）
训练 XGBoost 二分类模型的糖尿病风险预测 skill。
内置**已训练好的推理模型**，解压即可预测。

## 为什么有 v3：Pima 数据的人群限制

v1/v2 使用的 **Pima Indians Diabetes Database** 存在**三重人群限制**，
其官方原始文件（MD5 `3cbaa3e54586aa88cf6aacb4033e4470`，与公布值一致）明确写着：

> *"all patients here are **females at least 21 years old of Pima Indian heritage**"*

即 **仅女性** + ≥21 岁 + **仅 Pima 印第安人**，共 768 例。
数据中甚至没有性别列——不是漏采集，而是原始研究只纳入女性
（8 个特征中的 `preg` 怀孕次数也印证了这点）。

**v3 改用 NHIS 全人群抽样：**

| | v1/v2（Pima） | **v3（NHIS）** |
|---|---|---|
| 样本量 | 768 | **291,945**（380 倍） |
| 阳性数 | 268 | **31,760**（118 倍） |
| 性别 | **仅女性** | **男 143,524 / 女 158,681** |
| 族裔 | 仅 Pima 印第安人 | 全族裔 |
| 年代 | 1990 前后 | 2016–2025 |

## 只用风险因素，不含任何诊断性生化指标

**这是本模型的核心设计原则**：

- **不使用** HbA1c、空腹血糖等任何生化指标
- 理由：HbA1c ≥6.5% 与空腹血糖 ≥126 mg/dL **本身就是糖尿病的诊断标准**，
  用它们预测糖尿病近乎**循环论证**
- NHIS 数据本身也不含生化检验，该原则天然满足

确认糖尿病仍需依靠血糖 / HbA1c 检测，本模型仅用于**风险分层**。

## 特征如何选出（实测依据）

| 特征集 | 特征数 | CV AUC | 增量 |
|--------|--------|--------|------|
| 核心风险因素（年龄/BMI/身高/体重/吸烟） | 5 | 0.7677 | — |
| **+ 高血压/高胆固醇 ← 采用** | **7** | **0.8124** | **+0.045** |
| + 冠心病/脑卒中/慢阻肺 | 10 | 0.8162 | +0.004 |

- 高血压/高胆固醇是**代谢综合征组分**，标准糖尿病风险评分（FINDRISC 等）即包含 → **保留**
- 冠心病/脑卒中/慢阻肺是糖尿病的**并发症**（反向因果），且仅 +0.004 → **排除**

## ⚠️ 特征重要性存在严重误导性，务必先读

模型给出的重要性是：`hypertension` 0.4684 > `high_chol` 0.4056 > `age` **0.0678** >
`bmi` 0.0341 …。**看起来像"高血压是糖尿病最重要的风险因素，年龄几乎不重要"——这是错的。**

**实测证据**：去掉高血压/高胆固醇后重训，
**年龄重要性从 0.068 升到 0.630，BMI 从 0.034 升到 0.221**。
即年龄的信号被与之相关的高血压/高胆固醇**吸收**了（树模型的 gain 重要性偏向二值特征）。

**单变量患病率梯度**（更能反映真实风险强度）：

| 变量 | 最低档 | 最高档 | 倍数 |
|------|--------|--------|------|
| 年龄 | 18–29 岁 1.14% | 70–85 岁 19.46% | **17×** |
| BMI | 10–25 5.14% | ≥35 20.60% | 4.0× |
| 高血压 | 无 4.43% | 有 22.07% | 5.0× |
| 高胆固醇 | 无 5.49% | 有 22.52% | 4.1× |

年龄梯度实际**最宽**，与流行病学一致。

**另有检出偏倚**：横断面设计中，高血压/高胆固醇与糖尿病的强关联里，
既含真实代谢综合征关联，也含"确诊糖尿病者被更多筛查从而查出这些病"的成分，
二者**无法分离**。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 个体预测（3 项核心 + 4 项可选）
python scripts/predict.py --age 55 --bmi 28.5 --smoker 4 \
    --height 170 --weight 82 --hypertension 1 --high-chol 1

# 3. 批量预测
python scripts/batch_predict.py --input examples/people.csv --output results/batch_results.csv
python scripts/batch_predict.py --input examples/people.csv --threshold 0.22

# 4.（可选）重新训练并验证
python scripts/train_model.py

# 5.（可选）从 CDC 重新下载并校验数据（10 个年度，约 45MB）
python scripts/fetch_data.py
```

## 数据处理要点

- **年龄跨时代统一**：2016–2018 的 `AGE_P` 上限为 85（表示"≥85"），
  2019+ 的 `AGEP_A` 可达 99；统一**封顶到 85**。
- **特殊码清洗**：身高 96/98/99 英寸、体重 996–998 磅表示"不可得"，已置为缺失。
- **标签口径统一**：2018 及以前 `DIBEV1` 有"临界（糖尿病前期）"编码，
  2019+ 该编码取消（前期由 `PREDIB_A` 单独询问）；
  两个时代统一按"1=是→阳性，2/3→阴性"处理。

## 重要提示

1. **不含生化指标**：确诊须依靠血糖 / HbA1c 检测，本模型只做风险分层。
2. **横断面数据**：做的是**病例识别**（已患病可能性），不是"未来 N 年发病风险"。
3. **未诊断人群**：NHANES 实测显示自报糖尿病 15.7% 而客观标准下 20.4%，
   "低风险"不等于没有糖尿病。
4. **自报数据**：身高体重亦为自报，自报 BMI 通常低估，肥胖端判别会失真。
5. **特征重要性有误导性**：见上文专门章节。
6. **人群适用性**：基于美国成人（2016–2025），迁移需重新验证。
7. **声明**：仅供风险分层辅助参考与教学演示，**不能替代专业医生诊断**。
