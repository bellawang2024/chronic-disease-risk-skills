# 数据溯源说明（DATA PROVENANCE）

本 skill 使用 **BRFSS 2017（美国行为风险因素监测系统）**，
来源权威、可逐字节追溯，且**目标人群为全人群，模型不使用性别、种族等任何人群划分属性**。

## 1. 数据来源

| 项目 | 内容 |
|------|------|
| 调查项目 | BRFSS (Behavioral Risk Factor Surveillance System) |
| 执行机构 | U.S. Centers for Disease Control and Prevention (CDC) |
| 调查年份 | 2017 |
| 目标人群 | **美国 50 州及属地的成年居民**（≥18 岁），不限性别、种族、地区、收入 |
| 调查方式 | 全美随机电话调查（固定电话 + 手机），全球规模最大的持续性健康电话调查 |
| 原始记录数 | **450,016** |
| 官方页面 | https://www.cdc.gov/brfss/annual_data/annual_2017.html |
| 数据下载 | https://www.cdc.gov/brfss/annual_data/2017/files/LLCP2017XPT.zip |
| 数据许可 | 美国政府公开数据（Public Domain），可自由使用 |

### 为什么选 BRFSS

1. **全人群**：覆盖全美 50 州及属地的成年居民，是"全人群"意义上的抽样调查，
   而非某个性别、族裔或临床亚组。
2. **样本量充足**：原始 45 万条记录，脑卒中阳性事件 **18,956** 例 —— 脑卒中属
   相对少见结局（患病率 4.22%），充足的事件数是获得稳定评估指标的前提。
3. **可追溯**：单一官方压缩包，可通过 SHA256 逐字节校验。

> 备选方案 NHANES 2017-2018 单周期脑卒中仅约 273 例，事件数过少、
> 评估指标会很不稳定，故未采用。

### 关于 CDC 压缩包的两个坑（脚本已处理）

1. **文件名含尾随空格**：解压后的文件名为 `LLCP2017.XPT `（末尾有一个空格），
   直接按 `LLCP2017.XPT` 打开会报"文件不存在"。
2. **体积较大**：XPT 解压后约 **1.29 GB**，解析约需 50 秒与约 2 GB 内存。
3. **User-Agent 过滤**：CDC 的 CDN 对浏览器 UA 与自定义 UA 均返回 **403**，
   仅 curl 风格 UA 可通过。脚本内置多种 UA 依次尝试，全部失败时回退到系统 curl。

## 3. 建模队列构建规则（完全可复现）

1. **读取**：解析 BRFSS 2017 原始 XPT（450,016 条记录 × 358 列）。
2. **纳入**：`CVDSTRK3` 有作答记录者。
3. **结果**：**448,666** 条，其中阳性（曾被医生告知脑卒中）**18,956** 条，
   患病率 **4.22%**；多数类基线准确率 **95.78%**。

### 标签定义

`CVDSTRK3` —— BRFSS 核心问卷变量："曾被医生告知患有脑卒中"
（Ever told you had a stroke）。编码 1 = 是，2 = 否，7/9 = 不知道/拒答（按缺失处理）。

### 特征列表（15 个）

| 列名 | 含义 | 来源变量 | 编码 | 缺失数 |
|------|------|----------|------|--------|
| age | 年龄 | `_AGE80` | 岁，18–80（80 表示 ≥80） | 0 |
| bmi | BMI 体重指数 | `_BMI5` | `_BMI5 ÷ 100` | 36,235 |
| height_cm | 身高 | `HTM4` | cm | 16,301 |
| weight_kg | 体重 | `WTKG3` | `WTKG3 ÷ 100` | 29,689 |
| smoker | 吸烟状态 | `_SMOKER3` | 1=每天 2=偶尔 3=已戒 4=从不 | 18,614 |
| diabetes | 糖尿病 | `DIABETE3` | 1=是 → 1；其余 → 0 | 659 |
| hypertension | 高血压（医生告知） | `_RFHYPE5` | **2=是 → 1；1=否 → 0** | 1,302 |
| high_chol | 高胆固醇（医生告知） | `_RFCHOL1` | **2=是 → 1；1=否 → 0** | 51,253 |
| gen_health | 自评健康状况 | `GENHLTH` | 1=优 … 5=很差 | 1,122 |
| exercise | 过去 30 天休闲运动 | `_TOTINDA` | 1=是 → 1；2=否 → 0 | 34,037 |
| education | 教育程度 | `EDUCA` | 1–6 | 1,661 |
| income | 家庭年收入档 | `INCOME2` | 1–8 | 74,642 |
| drinks_wk | 每周饮酒量 | `_DRNKWEK` | **`_DRNKWEK ÷ 100`**，杯/周 | 29,892 |
| depression | 抑郁障碍（医生告知） | `ADDEPEV2` | 1=是 → 1 | 1,961 |
| copd | 慢阻肺/肺气肿 | `CHCCOPD1` | 1=是 → 1 | 2,098 |

## 4. 编码方向核对（重要）

BRFSS 中不同变量的 1/2 含义**并不一致**，若统一按"1=是"处理会导致特征方向反转。
本次构建对每个变量都做了显式核对，方法是用**原始来源变量做交叉表**验证：

| 派生变量 | 交叉核对依据 | 结论 |
|----------|--------------|------|
| `_RFHYPE5` | 与 `BPHIGH4`（1=Yes）交叉表：`BPHIGH4=1` 全部对应 `_RFHYPE5=2` | 1=否，2=是 |
| `_RFCHOL1` | 与 `TOLDHI2`（1=Yes）交叉表：`TOLDHI2=1` 全部对应 `_RFCHOL1=2` | 1=否，2=是 |
| `_TOTINDA` | 均值年龄：取值 1 → 较年轻，符合"有运动" | 1=是 |
| `ADDEPEV2` | 均值年龄：取值 1 → 53.1 岁 | 1=是 |
| `CHCCOPD1` | 均值年龄：取值 1 → 63.3 岁，符合"有 COPD" | 1=是 |

另外还做了**临床合理性自检**（阳性率应落在已知流行病学区间）：

| 指标 | 本数据集阳性率 | 美国成人已知水平 |
|------|----------------|------------------|
| 高血压（自报） | 40.31% | 约 35%–40% |
| 高胆固醇（自报） | 39.27% | 约 30%–40% |
| 糖尿病（自报） | 13.43% | 约 12%–14% |
| 当前吸烟 | 14.09% | 约 14%–17% |
| 有休闲运动 | 72.43% | 约 70%–75% |
| 慢阻肺 | 8.36% | 约 6%–9% |

**最有力的自检是脑卒中率随年龄的单调上升**（与流行病学完全一致）：

| 年龄段 | 卒中率 | 样本数 |
|--------|--------|--------|
| 18–30 | 0.49% | 53,695 |
| 30–40 | 0.98% | 51,935 |
| 40–50 | 2.24% | 58,961 |
| 50–60 | 3.86% | 86,598 |
| 60–70 | 5.36% | 102,493 |
| 70–80 | 8.45% | 94,984 |

### 关于 `_DRNKWEK` 的两个陷阱

1. **缩放**：该变量为"杯/周 × 100"，直接使用会得到中位数 23 这类不合理值；
   除以 100 后中位数为 0.23 杯/周，符合实际。
2. **零值编码**：非饮酒者并非编码为 0，而是一个**极小非规格化浮点数**
   （约 `5.4e-79`，SAS 传输格式的 0 表示）。脚本中按 `< 0.005` 归零处理。

## 5. 不使用人群划分属性（结构性保证）

**性别（`SEX`）与种族（`_RACE`）在数据构建阶段完全没有被提取**，
未出现在 `data/stroke_brfss.csv` 中，因此随附模型在结构上不可能使用任何
人群划分属性，而非仅在训练时忽略。

此外，**冠心病/心梗结局变量（`_MICHD`、`CVDCRHD4`、`CVDINFR4`）也未作为特征使用**，
以避免"用同类心血管结局预测另一个结局"造成的语义混淆与检出偏倚放大。

特征全部为年龄、体格、生活方式与疾病史等**与人群归属无关**的指标。

## 6. 缺失值

派生 CSV 保留原始缺失（空值），由训练/推理时的
`SimpleImputer(strategy="median")` 按训练中位数插补。
推理时**主要临床风险因素必须显式提供**，仅次要指标允许插补 ——
否则等于假设患者"没有该风险因素"，会系统性低估风险。

主要风险因素（必须提供）：`age, bmi, smoker, diabetes, hypertension, high_chol`
次要指标（可省略并插补）：`height_cm, weight_kg, gen_health, exercise, education,
income, drinks_wk, depression, copd`

## 7. 复现方式

```bash
# 从头重建数据集（下载 107MB → 校验 SHA256 → 解压 → 解析 → 构建）
python scripts/fetch_data.py

# 仅校验已有 CSV
python scripts/fetch_data.py --check

# 重新训练并验证

```

## 8. 使用限制与声明（重要）

1. **横断面数据，不是发病风险预测**：BRFSS 在单一时点询问"是否曾被医生告知患病"，
   因此本模型预测的是**已患病的可能性（病例识别）**，
   而非"未来 N 年发病风险"，与前瞻性队列风险模型含义不同，不可混用。
2. **关键危险因素缺失**：脑卒中的重要危险因素 —— **心房颤动、颈动脉狭窄、
   抗凝治疗、既往 TIA** —— BRFSS 核心问卷**未覆盖**。
   这是本模型 AUC（0.81）低于同类冠心病模型（0.85）的主要原因，
   也意味着**模型不应被当作完整的卒中风险评分使用**。
3. **检出偏倚 / 反向因果**：已确诊脑卒中的人更可能被反复检查、从而被查出高血压，
   也更可能自评健康较差。这会使"高血压""自评健康"的重要性被高估
   （二者恰为重要性前两位）。解读特征重要性时必须考虑这一点。
4. **自我报告**：风险因素与结局均为受访者自报，未经体检或病历核实，
   存在回忆偏倚与报告偏倚。特别是**卒中自报的准确性低于冠心病**，
   可能的误分类会削弱模型可达到的性能上限。
5. **准确率不是有效指标**：本任务阳性率仅 4.22%，多数类基线准确率即有 **95.78%**。
   请以 AUC、平衡准确率、敏感度/特异度为准（见 `SKILL.md`）。
6. **人群适用性**：模型基于**美国**成年居民数据（2017 年），
   应用于其他国家和地区人群时需重新验证。
7. **临床用途**：本模型仅用于健康风险筛查的辅助参考与教学演示，
   **不能替代专业医生的诊断**。
