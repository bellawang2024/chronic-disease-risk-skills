# 脑卒中（Stroke）风险预测模型

## 概述

基于**真实、可追溯、全人群**的公开权威数据集 BRFSS 2017（美国 CDC），
使用 XGBoost 训练脑卒中风险二分类模型。本 skill 内置**已训练好的推理模型**，
解压即可预测，无需重新训练。

| 项目 | 值 |
|------|-----|
| 任务 | 二分类（是否曾被医生告知患有脑卒中） |
| 算法 | XGBoost (`xgboost.XGBClassifier`) |
| 数据集 | BRFSS 2017（美国 CDC 行为风险因素监测系统） |
| **目标人群** | **美国 50 州及属地的成年居民（全人群抽样，不限性别、种族）** |
| 原始记录 | 450,016 → 建模队列 **448,666** |
| 特征数 | **15**（年龄、体格、生活方式、疾病史） |
| 阳性事件 | **18,956**（患病率 4.22%） |
| 划分 | test_size=0.2, random_state=42, stratify=True → 358,932 训练 / 89,734 测试 |
| 决策阈值 | **0.04**（由训练集交叉验证选定，不是 0.5） |

## ⚠️ 关于"准确率"的重要说明

本任务阳性率仅 **4.22%**，属于**高度不平衡分类**问题：

- **多数类基线准确率 = 95.78%**（即"全部预测为无卒中"就能得到 95.78% 的准确率）
- 本模型在留出测试集上的**普通准确率为 0.6799，反而低于该基线**

这不是模型失败，而是**准确率在罕见结局任务上失效**的典型表现
（accuracy paradox）。若强行把准确率刷到 95% 以上，只需把阈值调高、
几乎不预测阳性即可 —— 但那样的模型毫无筛查价值。

因此本 skill 的验收标准采用**不平衡分类的规范指标**：

| 指标 | 含义 |
|------|------|
| **AUC** | 排序能力，与阈值无关，不平衡任务的首选指标 |
| **平衡准确率** | (敏感度 + 特异度) / 2，对类别不平衡不敏感 |
| **PR-AUC** | 精确率-召回率曲线下面积，基线 = 患病率 0.0422 |
| 敏感度 / 特异度 | 在选定阈值下分别报告，便于按场景取舍 |

## 不使用人群划分属性（结构性保证）

**性别（`SEX`）与种族（`_RACE`）在数据构建阶段完全没有被提取**，
未出现在内置 CSV 中，因此模型在结构上不可能使用任何人群划分属性 ——
这不是"训练时忽略"，而是数据里根本没有。

此外，**冠心病/心梗结局变量（`_MICHD` 等）也未作为特征**，避免"用同类心血管结局
预测另一个结局"的语义混淆。全部 15 个特征均为与人群归属无关的指标。

## 功能

### 1. 预测个体风险（模型已内置，无需先训练）

需提供 **6 项主要临床指标**：

```bash
python scripts/predict.py --age 68 --bmi 28.0 --smoker 3 --diabetes 1 \
    --hypertension 1 --high-chol 1
```

| 参数 | 描述 | 取值 | 是否必需 |
|------|------|------|----------|
| `--age` | 年龄 | 18–80 岁（80 表示 ≥80） | **必需** |
| `--bmi` | BMI 体重指数 | 10–90 | **必需** |
| `--smoker` | 吸烟状态 | 1=每天 2=偶尔 3=已戒 4=从不 | **必需** |
| `--diabetes` | 糖尿病 | 1=有 0=无 | **必需** |
| `--hypertension` | 高血压（医生告知） | 1=有 0=无 | **必需** |
| `--high-chol` | 高胆固醇（医生告知） | 1=有 0=无 | **必需** |
| `--gen-health` | 自评健康状况 | 1=优 2=良 3=一般 4=差 5=很差 | 可选 |
| `--exercise` | 休闲运动（近 30 天） | 1=有 0=无 | 可选 |
| `--copd` | 慢阻肺/肺气肿 | 1=有 0=无 | 可选 |
| `--depression` | 抑郁障碍 | 1=有 0=无 | 可选 |
| `--height` / `--weight` | 身高/体重 | cm / kg | 可选 |
| `--education` | 教育程度 | 1–6 | 可选 |
| `--income` | 家庭年收入档 | 1–8 | 可选 |
| `--drinks-wk` | 每周饮酒量 | 杯/周 | 可选 |

> **为什么主要风险因素必须显式提供？**
> 若允许它们被中位数插补，等价于假设"该患者没有高血压/没有高胆固醇"，
> 会**系统性低估风险**。因此这 6 项作为必填项校验。
> 次要指标未提供时用训练中位数插补，并在输出的 `imputed_features` 中列出。

## 决策阈值为什么是 0.04

本任务阳性率仅 4.22%，模型输出的概率整体偏低，固定阈值 0.5 会导致
**敏感度 0.0000**（一个阳性都不报），模型完全不可用：

| 阈值 | AUC | 平衡准确率 | 敏感度 | 特异度 | F1 |
|------|-----|-----------|--------|--------|-----|
| 0.50（错误默认） | 0.8187 | 0.5000 | 0.0000 | 1.0000 | 0.0000 |
| **0.04（选定）** | **0.8187** | **0.7478** | **0.8219** | **0.6736** | **0.1783** |

阈值由**训练集交叉验证**在 0.01–0.80 范围内最大化平衡准确率选出，
得到 **0.04**，且**未使用测试集**。

> 卒中率随年龄从 0.49% 升到 8.45%，年龄本应是最强预测因子；
> 它排在第 3 反映的是"高血压"这一中介变量吸收了部分年龄效应。

## 注意事项

1. **关键危险因素缺失（最重要）**：心房颤动、颈动脉狭窄、抗凝治疗、既往 TIA
   等卒中核心危险因素**不在数据中**。因此本模型**不应被当作完整的卒中风险评分**，
   只能作为基于常规可获取指标的粗略风险分层工具。
2. **横断面数据，不是发病风险预测**：BRFSS 问的是"是否曾被医生告知患病"，
   本模型做的是**病例识别（已患病可能性）**，**不是**"未来 N 年发病风险"。
3. **检出偏倚**：见上文特征重要性解读警告。
4. **自我报告**：卒中自报的准确性低于冠心病等较为明确的诊断，
   误分类会削弱模型性能上限。
5. **准确率不适用**：见开头"关于准确率的重要说明"。
6. **人群适用性**：数据来自**美国**成年居民（2017 年），迁移到其他国家和地区需重新验证。
7. **临床决策**：本模型仅作为健康风险筛查的辅助参考与教学演示，
   **不能替代专业医生的诊断**。
